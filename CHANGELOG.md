# Changelog

## 1.0.0 — Portfolio Edition (2026-11-07)

- Created a responsive, standalone AFTERTONE case study suitable for GitHub Pages and other static hosts.
- Added a working, rights-safe mini demo with twelve fictional tracks and original Web Audio synthesized previews.
