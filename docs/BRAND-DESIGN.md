# AFTERTONE — Visual identity

AFTERTONE's marketing site follows the product's original signal icon, not the design system used for Keystoria.

## Brand tokens

- Signature lime: **#D6FB77**, from the existing mark's background
- Deep charcoal: **#0D1A1E**, from the mark's waveform
- Off-white paper: **#F4F6EF**, a quiet supporting neutral
- Sections may use white or a subtle grey-green tint. Do not introduce arbitrary lavender, coral or blue accent colors.

## Layout principles

- **A recognizable signal:** Hero art is an enlarged vector interpretation of the existing mark. The illustration is decorative, not a pretend screenshot of playback.
- **Editorial hierarchy, not dashboard cards:** Three listening paths are full-width rows. Music Duels is a typographic A-versus-B concept.
- **Accessible paths to the real app:** The header, primary hero CTA, mode rows, duel CTA and bottom CTA link to the full application at \`./demo/\`.
- **No fake product imagery:** The homepage avoids illustration presented as a real UI screenshot. Demo gameplay belongs in the actual /demo app.
- **Readable and responsive:** Explicit layouts for 1080px, 780px, 540px and 360px. Respect reduced-motion preferences and keyboard navigation.
- **Safe boundaries:** The app is untouched. The portfolio remains a standalone, JavaScript-free landing page with an inline provider/rights notice.

This document is a visual guardrail, not a mandate for the app's separate selectable player themes.
