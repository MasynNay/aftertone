# AFTERTONE v0.11.0 — Discovery, Durability & Music Duels

**November 11, 2026 · Public portfolio milestone**

AFTERTONE is a music-discovery portfolio application with a standalone homepage and a full interactive browser app. This release marks a tested stopping point after improvements to first-time listening, local saved-data portability, and tournament reliability.

## Highlights

- **A clearer first listen.** Inline three-step guidance helps listeners choose Comfort Zone, New Territory, or Wild Card, start a preview, and use Keep or Pass. Empty catalogs and searches provide non-destructive retry, clear-search, broader-filter and alternate-path options.
- **Better Deezer failure recovery.** Retry Preview, Skip Without Voting, Retry Discovery and isolated JSONP request cancellation help the app recover when third-party data or previews aren't available.
- **Portable listening progress.** Collection now offers validated JSON backup and restore for favorites, Keep/Pass history, preferences, tournaments, Tune Lab results, selected artists, imported playlist metadata, and lyric timing adjustments. New format v2 restores older v1 files. Audio is **not** exported.
- **Music Duels across six arenas.** Size-aware eligibility reflects 4/8/16-player brackets and the active song pool. Insufficient libraries show actionable guidance rather than fabricated tracks. Tournaments preserve selections and votes across refreshes, with bronze playoffs, podiums, and Hall of Fame CSV exports.
- **A stronger portfolio.** The homepage launches the original application directly. README screenshots, a development roadmap and step-by-step documentation explain the features and their implementation.

## Verified for this release

- **251/251 automated tests passed** on the Music Duels milestone's GitHub pull request.
- Desktop and mobile **Chromium** smoke tests opened the actual built portfolio, launched the original app, checked discovery, downloaded/restored progress, and completed a full four-song tournament with a mid-bracket refresh, final podium, CSV export, and archived reopen.
- GitHub Pages deployment checks now run before publication, so broken build imports or runtime errors can prevent a release from going live.

## Known limitations

**This is a portfolio preview, not a guarantee of production-ready licensed music playback.** Deezer catalog data, short preview playback, regional restrictions, browser policies, and media usage rights remain external dependencies; a site disclaimer alone does not establish authorization. Automated browser tests use fictional catalog fixtures and **do not verify live Deezer audio or rights**. Progress backups contain unencrypted listening metadata and should be kept private.
